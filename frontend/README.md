# HackMart-Frontend

HackMart is a vulnerable web application created to help students understand and explore the common web vulnerabilities.

This repository contains the **React.js + Material UI** of the HackMart project.

## ⚙️ Technologies Used

- Typescript
- React 19
- Material UI 5

## 🚀 Getting Started

### 1. Make sure **Node.js (Active LTS)** and **npm** are installed  
&nbsp;&nbsp;• Download Node.js: [https://nodejs.org/](https://nodejs.org/) (choose the **LTS** installer)  
&nbsp;&nbsp;• (Optional, Windows) Manage versions with nvm-windows: [https://github.com/coreybutler/nvm-windows](https://github.com/coreybutler/nvm-windows)

Verify installation:
```bash
node -v
npm -v
```

### 2. Install dependencies (from the frontend directory)
```bash
cd hackmart-frontend
npm install
```

### 3. Run the dev server
```bash
npm run dev
```
The app will start in development mode. If you use **Vite**, the default URL is usually:
```
http://localhost:3000
```
(Your terminal will print the exact address.)
